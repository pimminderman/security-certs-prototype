# Security certifications prototype

Interactive supplier overview, discovered certification documents, rich tooltips and persistent document detail panel.

## Preview locally

Run `python3 -m http.server 8000 --directory dist` and open http://localhost:8000.

Static HTML/CSS/JavaScript. Data is illustrative and fixed to the labelled snapshot date. Notes and risks last only for the current browser session.

Click a certification card to open Documents and highlight its corresponding row. Hover or focus a certification to see the rich tooltip. Select document rows to show the detail panel beside the table; changing records or tabs fades its content without reopening the panel.
