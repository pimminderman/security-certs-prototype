# Security certifications prototype

Interactive supplier overview, discovered certification documents, rich tooltips and document detail panel.

## Preview locally

Run `python3 -m http.server 8000 --directory dist` and open http://localhost:8000.

This is a static HTML/CSS/JavaScript prototype. Data is illustrative and fixed to the labelled snapshot date. Notes and risks are stored only for the current browser session.

Click a certification card to open Documents and highlight its corresponding row. Hover or focus a certification to see the rich tooltip.
